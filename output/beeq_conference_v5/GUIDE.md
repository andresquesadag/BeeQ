# BeeQ presentation guide · version 5 (English)

The current deck. Seventeen slides plus two supplementary ones after the
thank-you. Earlier revisions stay untouched in `beeq_conference_v4` (English),
`beeq_conference_v3` (English) and `beeq_conference_v2` (Spanish).

## How to open it

Double-click `index.html` in any modern browser. The file is self-contained,
photographs included: nothing is loaded from the network.

| Key | Action |
|---|---|
| `→` `space` `PgDn` | Next step, or next slide |
| `←` `PgUp` | Previous step, or previous slide |
| `Home` / `End` | First / last |
| `N` | Presenter notes |
| `F` | Fullscreen |
| `P` | Print or save as PDF |
| `T` | Rehearsal timer (against the planned 13:40) |

**To project:** press `F`.

## Reveals, and how they reach the PDF

Four slides build up in steps rather than showing everything at once:

| Slide | What is on screen first | What appears on the click |
|---|---|---|
| 4 · Context | the three steps | the bee strip and "BeeQ sits at the third step" |
| 6 · BeeQ893 | the claims: 1,035 → 893, binary endpoint | the partition chart, to talk through clusters |
| 8 · X10 | the molecule | the ten descriptor cards, all at once |
| 11 · Performance | the headline | the chart, with the claim and the AUROC gloss below it |

A PDF cannot animate, so the print build **splits each of those slides into one
page per step** — slide 4 becomes two pages, and so on. That is why the 19 slides
come out as a 23-page PDF. It is generated by `make_print.py`, which duplicates
the fragment slides before Chrome prints them; the on-screen deck is unaffected.

## What changed in this revision

- **Slide 4** — each of the three context cards is down to a single line.
- **Slide 6** — the dataset bullets are cut to the claim itself, and the
  **provenance of the 11 µg/bee threshold** now appears under the endpoint box:
  ApisTox, following U.S. EPA · Health Canada PMRA · California DPR, *Guidance
  for Assessing Pesticide Risks to Bees* (2014). That is the manuscript's own
  citation for this threshold.
- **Slide 7** — the selection / freeze / evaluation strip is replaced by the
  **outer/inner nested-CV figure** adapted from the BeeQ Slidev template
  (`output/BeeQ_Slidev_template`, its slide 06): five turns on the left, the
  four-fold inner loop on the right, the holdout set aside. The cluster
  statement stays underneath, now as a two-dot rule. The presenter notes for
  this slide were rewritten to match the new picture.
- **Slide 8** — **the descriptor cards now reach the PDF.** They are built by
  script, and the script filled only the first copy of the grid; the print build
  duplicates a slide once per reveal step, so the visible copy came out empty.
  It now fills every copy.
- **Slide 9** — rebuilt around the pair → similarity → table figure from the
  same template (its slide 08). The RBF formula is gone from the screen; the
  sentence above the figure is unchanged.
- **Slide 10** — the fidelity formula banner is gone. With that space the two
  circuits are now **separate, larger figures**, and the "rows omitted" mark sits
  clear of the gates. The Bloch sphere and the three scope bullets are unchanged.
- **Slide 14** — the title now reads "Structural similarity to a toxic neighbour
  was not enough".

Nothing quantitative changed. The two imported figures are schematics: the folds
and inner splits are drawn as equal blocks and are not to scale, and the 4 × 4
similarity table on slide 9 is illustrative. The real per-fold counts stay in SI
Table S9 and in `VERIFICATION.md`.

## Replacing the photographs

`team1.jpg` and `team2.jpg` live in this folder and are embedded into the HTML as
data URIs at build time. To swap them, overwrite the files and re-run
`assemble.py --deck=v5`. They were downscaled to 1200 px wide; the deck is
590 KB with both inside.

## Regenerating

From the repository root, with the project interpreter:

```bash
.venv/Scripts/python.exe output/beeq_conference_v2/build/make_charts.py --lang=en
```

```bash
.venv/Scripts/python.exe output/beeq_conference_v2/build/make_v4.py
```

```bash
.venv/Scripts/python.exe output/beeq_conference_v2/build/make_v5.py
```

```bash
.venv/Scripts/python.exe output/beeq_conference_v2/build/assemble.py --deck=v5
```

```bash
.venv/Scripts/python.exe output/beeq_conference_v2/build/make_print.py v5
```

- The generators live in `output/beeq_conference_v2/build/` and serve all four
  decks; `--deck=v2|v3|v4|v5` picks the output.
- The chain is `template_en.html` → `make_v4.py` → `template_v4.html` →
  `make_v5.py` → `template_v5.html`. If you edit V5 by hand, edit
  `template_v5.html` and do not re-run `make_v5.py`, which overwrites it.
- The slide 7 and slide 9 figures are drawn by `make_v5.py` itself, in Python,
  and inlined into the template.
- `gram_geometry.py` and `make_geometry_fig.py` rebuild the S1 figure. The first
  one prints the verification table against SI Table S22 and refuses to write its
  output if the reconstruction does not match.
- The QR uses **segno**, installed in the project venv. It is a build-time
  dependency only: the QR ships drawn inside the HTML.

The PDF is produced by printing `_print.html` from Chrome at 1600 × 900.
